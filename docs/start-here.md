# 시작하기 — 한 컷을 완성하고 한 편으로 연결하기

첫 목표는 진행 중인 작품에서 **한 CLIP을 화면·소리·편집까지 완성하는 것**입니다. 이 문서는 권장 제작 순서이며, 기존 시나리오와 승인된 장면을 바꾸는 지시가 아닙니다. 이미 완성한 단계는 건너뜁니다.

## 1. 오늘 준비할 자료

작업할 CLIP 하나의 최신 시나리오, 실제 기준 이미지, 가장 좋은 기존 영상이 있다면 그 파일을 준비합니다. 기준 이미지는 화풍·캐릭터·공간의 역할을 구분합니다. 길이·화면 비율·대사·후반에 넣을 문자는 확정본을 따릅니다. 새 도구를 설치하기 전에 자료가 서로 맞는지 확인합니다.

자료는 공개 GitHub에 올릴 필요가 없습니다. AI가 읽을 수 있는 작업 공간에 직접 제공하고, 작품 원문과 미디어는 별도로 관리합니다. GitHub에는 재사용할 제작 규칙과 도구를 둡니다.

## 2. 한 CLIP을 끝까지 완성합니다

| 순서 | 할 일 | 다음으로 넘어가는 기준 |
|---|---|---|
| 기준 확인 | 원문·참조·기존 결과를 대조 | 유지할 것과 이번 수정 범위가 분명함 |
| 연출 설계 | 핵심 감정, 눈에 보일 동작, 카메라, 시작·끝 상태 정리 | 한 컷이 전달할 의미를 한 문장으로 설명 가능 |
| 기준 이미지 | 얼굴·화풍·구도·의상·소품 확인 | 실제 이미지에 필수 요소가 맞음. 좋은 기존 영상이 있으면 생략 가능 |
| 영상 생성 또는 수정 | 확인한 서비스 설정으로 필요한 범위만 실행 | 동작·연속성·표정이 장면 의도에 맞음 |
| 소리·문자 편집 | 대사·생활음·배경 공간음·필요한 문자 배치 | 실제 청취와 재생에서 의미와 타이밍이 자연스러움 |
| 최종 검수 | 내보낸 파일을 처음부터 끝까지 재생 | 치명적 결함과 미확인 항목이 구분됨. 승인 여부는 사용자가 결정 |

모든 CLIP을 새로 생성하지 않습니다. 기존 영상의 화면이 적합하고 소리만 문제라면, 소리를 별도 편집하는 방법부터 비교합니다. 이 저장소에 오디오 합성·자동 편집 기능이 구현되어 있다는 뜻은 아닙니다.

## 3. 한 편을 연결합니다

기준 CLIP의 작업 방식을 나머지 CLIP에 적용합니다. 새 생성 순서는 가장 어려운 연기·손 동작·인물 접촉처럼 성공 여부가 불확실한 장면부터 검토하되, 확정된 이야기 순서는 유지합니다. 완성본을 이어 붙인 뒤 컷 사이 시선·손·소품 위치, 대사 끝부분, 공간음 연결, 메시지를 읽을 시간을 확인합니다.

제작용 원본 비율과 게시용 비율이 다르면 별도 출력본으로 만듭니다. 자동 중앙 크롭으로 인물이나 소품을 잘라내지 말고 실제 화면을 검수합니다. 플랫폼 출력 사양은 게시 시 확인합니다.

## 4. 다음 작품에 남길 기록

실제로 좋아진 프롬프트와 그 결과를 함께 보관합니다. 한 번의 수정에서는 핵심 변수 하나를 바꾸고 나머지는 유지합니다. 생성 결과에는 우연성이 있으므로 한 번 좋아졌다는 이유만으로 보편적인 공식으로 확정하지 않습니다.

- 첫 결과에서 채택한 CLIP 수 / 실제 생성 시도 수
- CLIP별 수정 이유와 실제 소요 시간
- 확인 가능한 실제 생성 비용
- 화면 수정과 음향 수정 중 어디에서 시간이 많이 들었는지

첫 작품의 기록을 기준선으로 삼습니다. 검증하지 않은 성공률이나 비용 절감률을 목표 성과처럼 쓰지 않습니다.

## 필요한 도구만 선택합니다

| 작업 | 우선 활용 | 추가 도입 시점 |
|---|---|---|
| 이미지·영상 생성 | 현재 쓰는 생성 서비스 | 현재 도구로 필요한 동작이 안 되는지 확인한 뒤 |
| 컷 편집·자막·음향 배치 | 이미 익숙한 편집기 하나 | 반복 불편이 확인될 때 FFmpeg 자동화 검토 |
| 효과음·한숨 등 녹음 편집 | 직접 녹음 또는 사용 권한 있는 소리 | 기존 편집기로 부족할 때 Audacity 등 검토 |
| 말한 내용을 자막으로 변환 | 실제 녹음이 있을 때 음성 인식 검토 | 확정 대본만으로 충분하면 Whisper 설치 불필요 |
| 웹·앱 소개 모션 | 실제 화면과 편집기의 간단한 움직임 | 같은 형식이 반복될 때 코드 기반 영상 모듈 검토 |

새 구독·20개 도구 일괄 설치·자동 업로드 구축은 첫 완성본의 전제 조건이 아닙니다. 사용자 PC의 설치 상태와 성능은 이 문서에서 확인하지 않았습니다.

## AI에게 작업을 맡기는 문장

이 문장은 저장소 파일과 첨부자료를 읽을 수 있는 AI 환경에서 사용합니다. 저장소 링크를 전달하는 것만으로 스킬이 설치되지는 않습니다.

> BB-PAK/BBPAK의 AGENTS.md와 skills/bbpak-video-director/SKILL.md를 읽고, 첨부한 최신 확정 시나리오·기준 이미지·기존 결과를 확인해 주세요. 이번에는 지정한 CLIP 하나만 화면·음향·후반 문자까지 완성하는 순서로 진행해 주세요. 먼저 유지할 요소, 실제 결함, 누락 자료, 가장 작은 다음 작업을 정리해 주세요. 기존 승인과 허용된 비용 범위는 유지하고, 새로 비용이 필요한 작업은 실행 전에 알려 주세요. 결과 파일을 확인하기 전에는 제작 완료로 표시하지 마세요.
