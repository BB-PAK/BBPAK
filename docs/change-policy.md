# 확정본과 변경 관리

1. 사용자의 최신 명시적 지시를 확인합니다.
2. 현재 확정본의 원문·파일·버전을 확인합니다.
3. 요청한 변경과 영향받는 CLIP을 적습니다.
4. 새 버전에서 그 범위만 수정합니다.
5. 실제로 비교한 항목과 아직 확인하지 못한 항목을 구분합니다.

프로필은 기본값입니다. 프로젝트별 지시가 우선하며, 원본 파일이 연결되지 않은 초기 프로필은 확정 시나리오 전체로 취급하지 않습니다.

| 기록 | 예 |
|---|---|
| 기준 파일 | `script-source.md`에 실제 원문 버전과 출처 기입 |
| 바꾼 항목 | CLIP1의 오른손 동작만 수정 |
| 유지 항목 | 대사, 컵 수, 의상, 조명, 길이 |
| 변경 이유 | 생성 결과에서 컵을 관통하는 손 관찰 |
| 상태 | 초안 / 사용자 승인 / 재작업 |

사용자가 승인하지 않은 제안을 `approved`로 바꾸지 않습니다. 잘못된 결과도 원인과 함께 남겨 같은 시도를 반복하지 않도록 합니다.
