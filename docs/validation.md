# 초기 버전 검증 기록

검증일: 2026-10-30 UTC.

- Python 테스트 8개 통과: 프로젝트 재실행 시 원문·프로필 보존, 잘못된 길이·중복 CLIP·경로 이탈 거부, 시각 입력 검사, 표본 개수 제한, FFmpeg 통합 검증.
- 2초 / 10fps 합성 영상에서 실제 길이 2초를 확인했습니다. 0.55초를 요청하면 다음 실제 프레임인 0.6초를 별도로 기록하는 것을 확인했습니다.
- 가변 프레임 간격의 합성 영상에서 0.35초 요청에 0.9초 프레임이 선택되었음을 기록하는 것을 확인했습니다.
- 스킬 4개의 구조 검사를 통과했습니다.
- 문서 내부의 상대 경로 링크를 확인했습니다.
- 초기 업로드 목록에 로컬 프로젝트 폴더와 미디어가 포함되지 않음을 확인했습니다.

이 검증은 문서·보조 스크립트의 검증입니다. 실제 생성 모델의 품질, 특정 제공자의 입력 호환성, 캐릭터 일관성, 음향 자연스러움은 실제 자료와 생성 결과로 별도 확인해야 합니다. 유료 생성 API는 호출하지 않았습니다.

재검증:

```bash
python -m unittest discover -s tests -v
```

FFmpeg 또는 FFprobe가 없으면 영상 통합 테스트가 건너뛰어집니다. 테스트 결과에 `skipped`가 있으면 전체 통합 검증을 완료했다고 표시하지 않습니다.
