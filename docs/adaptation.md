# 비비팍 작업에 맞춘 구성

## 설계 목표

반복되는 장면 제작에서 매번 기준을 다시 설명하는 부담을 줄입니다. 확정 시나리오를 보존하고, 실제 참조 파일을 연결하며, 필요한 부분만 수정하고, 비용을 발생시키는 작업과 문서 작성을 구분합니다.

공개 저장소에 재사용 가능한 작업 방법과 도구를 담습니다. 작품별 원문·캐릭터 이미지·미공개 결과는 별도 프로젝트 자료로 관리합니다. 원본에는 다양한 제작 분야와 도구가 섞여 있지만, 이 초기 버전은 이미지와 영상 프롬프트 및 결과 검수에 집중합니다.

## 원본과의 대응

| 원본 구성 | 이번 저장소에서 활용한 개념 | 현재 구현 범위 |
|---|---|---|
| ad-video-pipeline | 단계별 제작, 승인본과 참조 관리 | 제작 진행 스킬, 프로젝트 폴더 생성기 |
| nano-banana-pro | 이미지 입력과 참조 역할 구분 | 모델에 종속되지 않는 이미지 프롬프트 스킬. API 호출 없음 |
| seedance-25 | 참조·장면·시간별 동작·유지 조건 | 프롬프트 스킬과 새 생성·연장·국소 수정·연속성 지침. 사양은 실행할 서비스에서 확인 |
| higgsfield-seedance2-jineng | 장르에 맞는 동작·카메라·음향 설계 | 드라마·반실사 애니메이션·브랜드·제품 장면의 필요한 원리를 새로 정리. 15개 장르 전문은 복제하지 않음 |
| video-watch | 영상에서 확인 근거 추출 | FFprobe 메타데이터와 실제 프레임 시각을 기록하는 새 스크립트 |
| sfx-gen | 효과음 의도와 후반 처리 구분 | 음향 검수 지침. 생성·무음 제거·정규화 자동화 없음 |
| motion-pack | 설명용 모션그래픽 | 초기 버전에서 보류. 실제 수요 발생 시 별도 모듈 검토 |
| video-shotcraft | 웹사이트 소개 영상과 코드 기반 렌더링 | 초기 버전에서 보류. 캐릭터 장면 제작과 분리 |
| animate | 코드로 만든 모션 | 초기 버전에서 보류. 렌더링 도구를 포함하지 않음 |

## 의도한 작업 구분

- AI가 맡는 일: 원문 기반 정리, 참조 역할 연결, 프롬프트 작성, 실제 확인 범위 안의 검수와 수정 제안.
- 생성 서비스가 맡는 일: 참조와 프롬프트를 받아 실제 이미지·영상·음향 생성.
- 사용자가 결정하는 일: 창작 방향과 확정본, 비용 범위, 최종 승인, 공개할 작품 자료.
- GitHub가 맡는 일: 사용자가 공개를 승인한 제작 규칙과 도구의 저장 및 버전 관리.

파일을 올리는 것만으로 서비스 연결·모델 학습·완전 자동 제작이 생기지는 않습니다. 현재 구현한 범위와 앞으로 추가할 기능은 구분해서 기록합니다.

## 첫 완성본을 위한 선택

[시작 가이드](start-here.md)에 따라 기존 결과를 활용해 한 CLIP의 화면·음향·후반 편집까지 먼저 완료합니다. 원본의 기본 9:16·15초, 실사 피부 질감, 모든 컷의 2초 훅, 하드컷 일괄 금지 등은 공통 규칙으로 채택하지 않았습니다. 작품별 승인 기준과 실제 서비스 기능을 우선합니다.

반복 제작이 확인되기 전에는 추가 구독·20개 도구 설치·자동 업로드·새 웹앱을 선행 조건으로 두지 않습니다. 필요한 시점에 기존 편집기와 생성 서비스의 역할을 연결하고, 결과를 확인한 작업만 자동화 후보로 남깁니다.
