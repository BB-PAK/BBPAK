# 이미지 프롬프트 형식

## 제작 메모

CLIP / 버전 / 화면 비율 / 기준 원문 / 사용한 실제 참조 파일 / 참조 확인 상태.

## 복사용 프롬프트

1. 참조별 역할과 유지할 특징.
2. 장면의 인물·행동·표정·시간·공간.
3. 구도·렌즈 느낌·시점·프레임 밖으로 잘리지 않아야 할 요소.
4. 광원·색·질감·화풍.
5. 반드시 유지할 개수·위치·의상·소품.
6. 생성하지 않을 요소. 실제 프로젝트에 해당하는 제한만 간결하게 쓴다.

영문이 필요하면 위 내용을 의미 손실 없이 영문으로 작성하고, 사용자에게 변경 사항은 한국어로 설명한다. 영어 사용이 모든 모델에서 우수하다고 단정하지 않는다.

## 출력 뒤 확인

참조 파일이 실제 업로드되어 있는지, 한 장면인지, 인물과 소품 수가 맞는지, 편집용 문구가 이미지에 들어가지 않았는지 확인한다. 이미지에 여러 장면을 넣는 검수용 연락 시트와 최종 생성 이미지를 혼동하지 않는다.
