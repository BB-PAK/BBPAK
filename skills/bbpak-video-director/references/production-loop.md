# 한 컷 완성에서 한 편 완성까지

## 현재 위치부터 시작

최신 원문, 실제 참조, 기존 결과를 확인하고 `기준 확인 → 연출 → 기준 이미지 → 영상 → 소리·문자 편집 → 최종 검수` 중 아직 끝나지 않은 단계부터 시작한다. 이 순서는 권장 절차다. 사용자의 구체적인 요청이 우선이며, 새 창작 제안은 승인 전까지 확정 시나리오에 반영하지 않는다.

첫 실행에서는 한 CLIP을 완성해 재현 가능한 기준을 만든다. 모든 컷을 다시 만들거나 동일한 승인 질문을 반복하지 않는다. 이미 좋은 화면이 있으면 그 결과에서 음향·편집을 이어간다.

## 제작 전 한 장 기록

| 항목 | 적을 내용 |
|---|---|
| 기준 | 원문 버전, CLIP, 실제 참조 파일, 길이·비율 |
| 관객이 알아야 할 것 | 원문에서 확인되는 정보 또는 감정 하나 |
| 화면 행동 | 시작 상태 → 주요 동작 → 끝 상태 |
| 카메라 | 샷 크기·시점·고정/이동·화면 안 인물 위치 |
| 연속성 | 시선 방향, 사용하는 손, 소품 수·위치, 의상, 조명 |
| 소리와 문자 | 생성에 맡길 것 / 따로 녹음·편집할 것 |
| 이번 검증 | 가장 불확실한 요소 하나, 합격 판단 근거 |
| 실행 범위 | 허용된 도구·생성 수량·비용, 미확인 설정 |

처음 보는 인물의 외형이나 자료에 없는 대사를 채워 넣지 않는다. 새로운 타이밍은 `[제안]`으로 표시하고, 사용자에게 이미 타이밍이 있으면 유지한다.

## 수정 순서

1. 원문·참조·입력 설정이 맞는지 확인한다.
2. 잘못된 부분이 편집으로 해결되는지 판단한다.
3. 재생성이 필요하면 바꿀 변수와 유지할 기준을 적는다.
4. 새 결과를 이전 결과와 같은 구간에서 비교한다.
5. 좋아진 부분과 새로 나빠진 부분을 함께 기록한다. `v002`라는 이유로 최종본으로 고르지 않는다.

추가 생성은 기존 허용 범위를 확인하고 실행한다. 범위를 소진했거나 원인을 좁히지 못한 반복 실패가 이어지면 같은 요청을 계속 결제하지 말고 입력·동작·구도부터 다시 검토한다. 실행 전 제안한 수량을 사용자 승인 없이 늘리지 않는다.

## 한 편으로 연결

CLIP별로 마지막 사용 가능 프레임, 다음 컷의 첫 상태, 대사·효과음의 경계를 기록한다. 이어 붙인 전체를 재생하고 각 컷의 완성도뿐 아니라 감정의 흐름과 정보 전달을 확인한다. 에피소드 전체의 시작·변화·끝을 평가하되, 모든 CLIP에 독립적인 훅·반전·판매 문구를 추가하지 않는다.

성공한 방법은 프롬프트·참조·설정·결과·검수 기록을 한 묶음으로 보관한다. 자동화는 반복해서 검증한 작업부터 추가한다.
