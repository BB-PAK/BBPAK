# 필요한 장면에만 적용하는 연출 기준

아래는 창작 선택을 돕는 지침이며 생성 모델의 기능 보장이 아니다. 승인된 시나리오·화풍·구도를 우선한다. 새로운 연출은 `[제안]`으로 구분한다.

## 1. 감정을 눈에 보이는 행동으로 바꾼다

`슬프다`, `지쳤다` 같은 말만 반복하지 않는다. 원문 안에서 가능한 시선 변화, 손의 멈춤, 어깨의 이완, 호흡, 반응의 지연으로 구체화한다. 표정·손·몸통·카메라가 동시에 크게 움직이도록 쌓지 않는다.

동작은 준비 → 실행 → 반응 또는 멈춤으로 나누되, 짧은 컷에 불필요한 단계를 넣지 않는다. 이미 정해진 대사와 타이밍은 바꾸지 않는다. 연기 지시를 추가한다고 얼굴·체형·의상을 다시 디자인하지 않는다.

## 2. 장면 목적에 맞는 패턴을 고른다

| 상황 | 우선 설계할 것 | 피할 것 |
|---|---|---|
| 대사·표정 중심 드라마 | 눈과 손이 읽히는 구도, 상대를 보는 방향, 반응할 여유 | 매 구간 줌·팬 추가, 과장 표정 강제 |
| 반실사 애니메이션 | 기준 얼굴·선·명암 유지, 몸의 무게와 소품 접촉 | 모공 추가, 고무처럼 늘어나는 몸, 갑작스러운 화풍 교체 |
| 브랜드 소개 | 실제 문제·실제 작업·확인된 결과가 연결되는 장면 | 가짜 고객 사례·미검증 성과·장면마다 판매 문구 |
| 제품 사용 장면 | 실물 참조, 형태·색·라벨·크기 관계, 손의 접촉 | 보이지 않는 뒷면 발명, 제품 변형, 임의 기능 시연 |

브랜드·제품 패턴은 그 프로젝트에서만 사용한다. 드라마의 이야기를 광고 흐름으로 자동 변경하지 않는다.

## 3. 카메라는 한 가지 목적을 갖게 한다

| 목적 | 표현 예 | 함께 적을 제약 |
|---|---|---|
| 작은 표정 읽기 | close-up, locked-off camera | 시선 방향·머리 크기·남길 여백 |
| 손과 얼굴 함께 보기 | medium shot | 손과 소품이 프레임 안에 들어옴 |
| 두 사람 관계 보기 | over-the-shoulder shot | 어느 인물의 어깨인지, 상대 위치 |
| 중요한 순간에 집중 | slow push-in | 이동 방향·종료 구도, 피사체 위치 |
| 소품 정보 전달 | insert shot | 소품 외형·개수·다음 컷과 위치 연결 |

문장 예시는 어휘 설명이며 결과 보장이 아니다. 실제 카메라 이동과 렌즈 줌을 혼용하지 않는다. 고정 요청에 미세 핸드헬드를 추가하지 않는다. 동일 공간에서 좌우 배치나 시선 방향을 바꿔 관객이 혼란스러워지는지 확인한다.

## 4. 컷은 의미가 바뀔 때 나눈다

장소·시점·관객이 볼 정보가 바뀔 때 컷을 검토한다. 모델의 지원 길이만으로 전체 이야기를 다시 나누지 않는다. 생성 단위를 나눌 필요가 있으면 확정 CLIP 안에 제작용 샷을 두고 최종 길이와 순서는 유지한다.

일반적인 장면 연결에는 단순 컷을 사용할 수 있다. 모든 하드컷을 금지하지 않는다. 동작 중 연결은 손·물체 위치와 이동 방향을 맞추고, 반응 컷은 시선과 대사 경계를 맞춘다. 디졸브·페이드·휩팬은 의미가 있을 때만 제안한다. 편집으로 가능한 전환을 굳이 생성 모델에 맡기지 않는다.

## 5. 프롬프트를 짧게 다듬는다

중요도는 확정 장면·실제 참조 → 주요 행동 → 카메라 → 연속성·음향 → 필요한 금지 조건 순으로 정리한다. 상충하는 지시와 장식적인 품질 수식어를 제거한다. 금지문은 실제 위험에 맞춰 쓰고, 같은 문장을 모든 구간에 과도하게 복제하지 않는다.

설명 언어는 사용자 요청과 실제 서비스 동작에 맞춘다. 한국어 대사는 원문 그대로 둔다. 영어 작성이 모든 서비스에서 항상 우수하다고 단정하지 않는다.
