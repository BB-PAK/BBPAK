# 작업 방식 선택과 연속성

## 실행 설정 확인표

첨부된 과거 가이드의 숫자를 현재 제품 사양으로 사용하지 않는다. 실행할 서비스 화면 또는 공식 문서에서 다음을 확인하고 확인일·출처를 기록한다. 확인할 수 없으면 `[실행 설정 확인 필요]`로 남기고 문서 준비를 계속한다.

| 확인 항목 | 기록 |
|---|---|
| 서비스 / 실제 모델명 / 확인일 | |
| 사용 가능한 생성·연장·편집 방식 | |
| 길이·비율·해상도 / 오디오 지원 | |
| 입력 종류·수량 / 참조 지정 문법 | |
| 시작·끝 프레임 지정 지원 | |
| 실제 선택 옵션의 예상 비용·허용 수량 | |

## 요청별 선택

| 요청 | 프롬프트에 담을 내용 | 필요한 확인 |
|---|---|---|
| 새 장면 생성 | 참조 역할·전체 장면·시간별 행동·유지 조건 | 실제 첨부와 입력 문법 |
| 기존 영상 연장 | 원본 끝 자세·손·소품·시선·카메라·다음 행동 | 해당 서비스의 연장 기능과 원본 구간 처리 |
| 일부 수정 | 대상·바꿀 속성·정확한 구간·유지할 요소 | 국소 편집 지원과 실제 결과의 주변 변화 |
| 긴 장면 또는 여러 컷 | 장면별 역할·입출력 상태·편집 연결점 | 단일 생성 가능 여부, 나눌 경우 사용자의 확정 구조 |
| 3D 작업물의 외관 변환 | 입력 모델·카메라·재질·조명의 유지/변경 범위 | 실제 3D 자료와 해당 변환 기능. 일반 드라마의 기본 단계가 아님 |

원본 가이드의 Omni Reference, Long Video, Extend, Smart Edit, Clay Renderer는 참고 명칭이다. 현재 선택한 서비스에 모두 존재한다고 가정하지 않는다. 지원되지 않는 기능은 일반 생성으로 가장하지 말고 대안을 구분한다.

## 연장과 편집의 핵심

연장은 기존 영상의 마지막 사용 가능한 구간을 확인한 뒤 설계한다. 앞 컷에서 오른손에 든 물건이 다음 컷 왼손에 생기지 않도록 시작 상태를 명시한다. 서비스가 마지막 프레임 입력을 지원하면 실제 파일을 사용하고, 지원하지 않으면 지원되는 입력 방법으로 바꾼다.

국소 수정 요청에는 `어느 파일의 어느 구간에서 무엇을 어떻게 바꾸며 무엇을 유지할지`를 적는다. 모델이 원본의 나머지 구간을 보존한다고 보장하지 않는다. 수정본 전체를 원본과 비교하고 기존 파일은 별도 보관한다.

## 시간·대사·소리

- 타임라인은 컷 내부 상대 시간과 에피소드 시간을 구분한다. 최종 합계가 확정 길이와 맞는지 계산한다.
- 시간 지시는 목표다. 실제 동작·입 모양·효과음이 정확히 그 초에 발생했다고 미리 보증하지 않는다.
- 긴 대사가 정해진 시간에 들어가는지는 직접 읽거나 실제 음성을 재생해 확인한다. 맞지 않으면 대사·길이를 임의 수정하지 말고 선택지를 제시한다.
- 효과음과 화면 메시지는 생성에 맡길 것과 편집에서 넣을 것을 명확히 나눈다. 후반 문자를 생성 화면에 중복해서 넣지 않는다.
