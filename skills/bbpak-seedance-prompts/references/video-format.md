# 영상 프롬프트 형식

## 실행 메모

프로젝트 / CLIP / 버전 / 목표 길이 / 화면 비율 / 제공 서비스 / 모델 / 실제 확인한 설정.

미확인 설정은 프롬프트 안에서 확정 사양으로 쓰지 않는다.

## 복사용 본문

**참조 역할**

실제 첨부 파일과 그 역할을 대응한다. 누락된 파일을 가상의 이미지 번호로 채우지 않는다.

**전체 장면**

확정 시나리오의 한 장면을 기술한다. 분위기와 시각적 사건을 연결한다.

**시간별 동작**

| 구간 | 인물 동작·표정 | 카메라 | 대사·생활음 |
|---|---|---|---|
| 시작–중간 | 승인 원문 기반 | 고정/이동 여부 | 실제 승인 문구 또는 의도된 무음 |
| 중간–끝 | 이전 동작에서 연속 | 불필요한 변화 없음 | 승인 원문 기반 |

실제 길이에 맞게 행을 조정한다. 생성 서비스가 표보다 문장을 적절히 받는다면 같은 내용을 시간 표시 문장으로 변환한다. 사용자가 준 타이밍은 유지하고, 새 타이밍은 제안으로 표시한다.

**유지 조건**

인물 정체성 / 의상 / 소품 수와 위치 / 광원 / 화풍 / 화면 문자 처리 / 금지한 행동.

## 사전 검토

- 모든 구간의 합이 목표 길이와 일치하는가?
- 실제 참조 첨부와 참조 역할이 일치하는가?
- 동시에 불가능한 손 동작이나 카메라 지시가 없는가?
- 대사·생활음·후반 편집 요소가 구분되어 있는가?
- 이미 확정한 이야기나 화풍을 바꾸지 않았는가?
