# 음향과 최종 편집 검수

## 화면과 소리를 따로 판단

화면이 적합하면 소리만 수정할 수 있는지 먼저 비교한다. 기존 대사와 효과음이 한 트랙에 섞여 있으면 완전 분리가 보장되지 않으므로, 원본을 보존하고 분리 과정의 왜곡을 직접 듣는다. 승인받은 대사를 임의 재녹음하거나 새 목소리로 바꾸지 않는다.

## 소리 배치표

시간은 해당 CLIP의 시작을 0초로 한다. 계획한 시각과 실제 적용한 시각을 구분한다. 확정 시각이 없으면 제안으로 표시한다.

| 소리 | 계획 시각 / 실제 시각 | 화면의 계기 | 확보한 파일·출처 | 배치와 청취 결과 |
|---|---|---|---|---|
| 대사 | | 입 동작 또는 속마음 | 승인 원문·녹음 파일 | 단어 끝 잘림·중복·입 모양 |
| 생활음 | | 접촉·발걸음·알림 등 | 직접 녹음 / 사용 권한 있는 파일 / 생성 | 소리와 행동의 선후 관계 |
| 호흡 | | 감정·자세 변화 | 실제 확보 파일 | 과장·신음처럼 들리는지 |
| 공간음 | | 장소와 시간대 | 실제 확보 파일 | 컷 사이 갑작스러운 무음 |
| 음악 | | 작품에서 요청한 경우 | 사용 권한·파일 | 대사 가림·의도한 침묵 훼손 |

알림은 인물 반응을 일으킬 수 있고, 접촉음은 화면 접촉과 맞아야 한다. 모든 소리를 같은 시각에 몰지 않는다. 선택적인 연출을 실제 원문에 있었던 것처럼 쓰지 않는다.

## 자연스러운 호흡과 효과음

한숨은 실제 들었을 때 짧은 날숨과 호흡의 흐름으로 인식되는지 확인한다. 단어로 `sigh`를 넣었다는 이유로 자연스럽다고 판정하지 않는다. 직접 녹음 또는 사용 권한이 있는 파일을 검토하고, 재생성은 기존 허용 범위 안에서만 실행한다.

파형의 크기나 음성 인식 결과만으로 음색·감정을 판정하지 않는다. 노이즈 제거·무음 삭제·정규화는 필요한 구간에 적용하고 숨, 여운, 생활음 사이 간격이 사라졌는지 확인한다. 음량 목표는 실제 출력 목적에 맞춰 정하며 임의의 수치를 모든 플랫폼 표준으로 선언하지 않는다.

## 후반 편집과 내보내기

1. 원본 영상·오디오를 보존하고 편집본을 별도 버전으로 만든다.
2. 대사·효과음·공간음·음악을 가능한 범위에서 구분해 배치한다.
3. 승인된 자막·메시지·로고를 지정 구간에 넣는다. 글자 생성은 영상 모델의 성공 여부에 맡기지 않는다.
4. 컷 경계에서 대사 끝·호흡·잔향이 잘리지 않는지 듣는다. 소리만 문제가 있는 컷을 자동으로 전체 재생성하지 않는다.
5. 편집기 미리보기와 별도로 실제 내보낸 파일을 전체 재생한다. 길이·크기·싱크·검은 프레임·문자 가독성을 확인한다.
6. 가능하면 이어폰과 휴대전화 스피커에서 확인하고, 확인하지 못한 재생 환경은 기록한다.

## 결과 상태

화면·음향·문자·컷 연결을 각각 `적합 / 수정 필요 / 미확인`으로 기록한다. 핵심 항목이 미확인이면 전체 검수 완료로 표시하지 않는다. 관객이 이해하지 못하는 행동, 인물·제품 정체성 변화, 중요한 대사·음향 누락은 우선 수정 대상으로 삼는다. 사소한 취향 차이는 별도 제안으로 두고 사용자가 최종본을 선택한다.

이 문서는 편집·검수 지침이다. 저장소의 `inspect_video.py`는 프레임과 메타데이터만 추출하며, 오디오 합성·청취·자동 완성본 출력 기능은 없다.
